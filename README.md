# Projet-CAPI(Planning poker)

## Présentation
une application qui permet à une équipe de jouer une partie de planning poker en respectant les règles vues en cours (cours « Méthodes agiles », « Scrum : point sur l'estimation »)

## Fonctionnalités

- saisie du nombre de joueurs et de leurs pseudos
- chargement d’un backlog JSON
- affichage des fonctionnalités.
